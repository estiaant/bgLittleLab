# Curriculum and assessment reference links

These links support the curriculum context for this **illustrative** learning prototype. The game is **not** a DBE product and does not represent a DBE-endorsed exam prediction.

- [DBE Grade 12 Examination Guidelines landing page](https://www.education.gov.za/2021Grade12ExamGuidelines.aspx): explains external examination scope and how guidelines relate to CAPS.
- [DBE Physical Sciences Grade 12 Examination Guidelines (English, PDF)](https://www.education.gov.za/Portals/0/CD/2021%20Exam%20Guidelines/Physical%20Sciences%20GR%2012%20Exam%20Guidelines%202021%20Eng.pdf): see scientific investigation skills, variables, fair tests, graph interpretation, conclusions, momentum, free fall, work/energy/power and reaction rates.
- [DBE 2023/24 Grade 12 Physical Sciences ATP (PDF)](https://www.education.gov.za/Portals/0/Documents/Recovery%20plan%20page/2023%20ATPs/FET%20Content%20Subjects/Grade%2012/1.540%20ATP%202023-24%20Gr%2012%20Phys%20Sci%20final.pdf): teaching plan and indicated practical activities. Verify the applicable annual/provincial guidance for any formal SBA programme.

Actual NSC examinations can test the scientific skills in new scenarios; these four selected experiments are a teaching sample, not an exhaustive bank of examinable investigations. All diagrams, visual assets, source code, and explanation text in this ZIP are newly authored, and no official PDFs are redistributed.
